## Artifact Descriptions and Schemas

### 1. `circuits/seed{N}.json`
Records the minimal subnetwork $C^*$ identified by greedy backward pruning, along with causal hypothesis testing results:
- `circuit_components`: List of head identifiers in format `L{layer}H{head}`.
- `metrics.sufficiency_accuracy`: Performance when keeping *only* $C^*$ active (ablating all $\mathcal{H} \setminus C^*$).
- `metrics.necessity_ablated_accuracy`: Performance when removing *only* $C^*$ (keeping $\mathcal{H} \setminus C^*$ active).
- `metrics.random_control_sufficiency_mean`: Mean sufficiency accuracy of random subsets of size $k = |C^*|$.

### 2. `patching/seed{N}.csv`
Records normalized Causal Effect (CE) for all 16 attention heads:
$$\text{CE}(l, h) = \frac{P_{\text{patched}}(y^*) - P_{\text{corrupt}}(y^*)}{P_{\text{clean}}(y^*) - P_{\text{corrupt}}(y^*)}$$
- `clean_probability`: Model baseline confidence on clean target under unperturbed input.
- `corrupted_probability`: Baseline confidence on clean target under counterfactual corrupted input.
- `patched_probability`: Confidence on clean target when restoring head $(l, h)$ during corrupted run.

### 3. `stability/cross_seed_stability.json`
Stores cross-seed evaluation over seeds `[42, 123, 456, 789, 1000]`:
- `mean_structural_jaccard`: Pairwise off-diagonal Jaccard similarity across discovered circuit component sets.
- `mean_functional_correlation`: Pairwise Pearson correlation between full 16-dimensional causal effect vectors.

### 4. `tables/ood_evaluation.csv`
Compares full model vs. discovered minimal circuit accuracy across 4 evaluation splits:
1. `In-Distribution`: Canonical 2-entity associative recall pairs.
2. `OOD-1 (Unseen Entities)`: Disjoint entity subset.
3. `OOD-2 (Distractors)`: Injected distractor key-value pairs before query.
4. `OOD-3 (Longer Context)`: Scaled sequence with 3 key-value pairs.
